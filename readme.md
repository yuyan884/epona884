## レンタルサーバー検討

### 条件

- HTML、CSS、JavaScript で構成する静的なページに対応(Webアプリは構築予定は今のところなし)
- 商用利用可能
- 広告は付かない
- 静的ページの利用で比較的安価なサーバー(もしくは無料)
- 日本国内サーバー

**おすすめの絞り込み方**

- とにかく安く始めたい → さくらのレンタルサーバ ライトプラン、またはロリポップ エコノミープラン（どちらも月121円〜、静的サイトに特化した設計でオーバースペック不要）
- 将来的にお問い合わせフォームのCGI/PHPや少し高度な機能も使う可能性がある → XREA Plus（200GBと容量にも余裕）
- サポートの手厚さ・知名度・将来WordPress化の可能性も見ておきたい → Xserver または ConoHa WING（やや割高）

無料プラン（XREA Free、スターサーバー無料など）は容量・転送量の制限が厳しく、広告が付くプランもあるため、商用の公式サイトとしては有料の格安プランをおすすめします。

なお、正確な最新料金・利用規約（商用利用の可否や広告の扱いの細目）は変更されることがあるため、契約前に各社の公式サイトで最終確認してください。
